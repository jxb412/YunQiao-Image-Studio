# v0.1.23

## 图生图选图彻底改成本机文件选择

- 底图区不再依赖主进程自定义对话框，改为标准文件选择控件（`<input type="file" multiple>`），点击“选择本机底图”即弹出系统文件选择框，选中的图片直接载入软件内显示与编辑。
- 支持拖拽导入：把图片拖到同一区域即可。
- 支持格式：PNG / JPG / WEBP / GIF / SVG；GIF 取首帧、SVG 按原始尺寸渲染，统一栅格化为 PNG 后再写入临时文件参与编辑，长度超过 2048px 自动等比缩放。
- 选择失败、读取失败、格式不支持都会给出明确提示。
- 结果区工具栏“文件位置”已改名“打开所在文件夹”，避免与选图入口混淆。

## 模型

- 支持 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`。
