# v0.1.19 更新说明

## 重点更新

- 版本号、客户端文件名、README、用户手册和交付文档统一更新到 `v0.1.19`。
- 确认 GPT 与 Gemini 图像接口统一使用 quya.org 服务；客户端固定服务地址，不提供自定义 API URL。
- 保留多 Key、多模型配置，可获取模型列表，并在顶部模型选择器切换当前生图模型。
- Gemini 图像模型继续支持 `gemini-3.1-flash-image` 生图、图生图和 AI 修图。
- GPT 与 Gemini 参数区保持分离：GPT 使用尺寸、质量、格式、背景等参数；Gemini 使用输出大小和画幅比例。
- 批量生产工坊、AI 修图工具箱、检查更新和代理网络逻辑继续跟随当前模型配置。

## 验证

- 已通过 `npm run lint`
- 已通过 `npm run typecheck`
- 已通过 `npm test`
- 已通过 `npm run build`
