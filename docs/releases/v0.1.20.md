# v0.1.20 更新说明

## 重点更新

- 新增 `gpt-image-2.5-flare` 和 `gpt-image-2.5-sunburst` 模型支持。
- 设置页默认 GPT 模型列表、顶部模型选择器、模型列表获取和模型请求均支持两个新模型。
- 已保存的旧 GPT 配置会自动补齐新模型，不需要重新添加 API Key。
- 文生图、图生图、局部重绘、AI 修图和批量生产会使用顶部当前选择的 GPT 图像模型。
- 保持单张生成策略，不传递图片数量参数，避免中转服务将该参数转换为不兼容的 `tools[0].n`。
- README、产品规范、技术 API 规范、用户手册和核心测试同步更新。
