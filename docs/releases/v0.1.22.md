# v0.1.22

## 新增模型

- 支持 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst` 两个 GPT 图像模型，默认模型仍为 `gpt-image-2`。
- 模型列表、顶部模型切换器、设置页与批量生产全部同步支持新模型，旧配置自动补齐，无需重新填写 Key。

## 图片格式

- 图生图 / AI 修图支持载入 `GIF` 与 `SVG`：载入时自动栅格化为 PNG（GIF 取首帧，SVG 按原始尺寸渲染，最长边不超过 2048px），再提交给图像接口，避免接口拒绝非 PNG/JPG/WEBP 输入。
- 文件选择对话框、扩展名校验、MIME 推断同步支持 `gif`、`svg`。
- 批量工坊仍只扫描 PNG/JPG/WEBP，避免批量任务里混入无法直接提交的格式。

## 交互修复

- 图生图/AI 修图底图区域支持**拖拽导入**：把图片拖到“点击选择底图”区域即可载入并进入编辑，不再需要依赖系统看图软件。
- 底图区域文案改为“点击选择底图，或把图片拖到这里（PNG/JPG/WEBP/GIF/SVG）”，明确操作方式。
- 结果区工具栏“文件位置”改名为“打开所在文件夹”，避免被误认为“选择图片”入口。
- 选择图片、格式转换失败都会给出明确提示，不再出现点了没反应或图片跳到系统程序打开的情况。
