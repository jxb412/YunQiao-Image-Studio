# v0.1.18 更新说明

## 重点更新

- 新增 Gemini 图像模型接入，支持 `gemini-3.1-flash-image` 生图、图生图和 AI 修图。
- API 设置升级为多 Key、多模型配置；添加 Key 后可获取模型列表，并在顶部模型选择器切换当前生图模型。
- GPT 与 Gemini 图像接口统一使用 quya.org 服务；客户端固定服务地址，不提供自定义 API URL。
- GPT 与 Gemini 参数区分离：GPT 使用尺寸、质量、格式、背景等参数；Gemini 使用输出大小和画幅比例。
- Gemini 返回图片会读取真实 MIME 类型，结果面板显示返回类型、图片类型、尺寸、文件大小、耗时和错误状态。
- 批量生产工坊跟随当前模型，支持 GPT/Gemini 文生图与图生图任务，并按模型显示尺寸规则。
- 文档同步更新：README、用户手册、技术 API 规范、交付说明。
