# v0.1.21

## 界面与体验

- 重做顶部模型切换器：自绘深色浮层替代原生下拉，彻底修复白色背景 + 浅色文字导致模型名看不清的问题，支持 provider 徽标、配置名、勾选态、点击外部与 Esc 关闭。
- 统一深色设计令牌：顶栏玻璃拟态、按钮/输入框/卡片/表格/弹窗/滚动条整体重绘，补齐指标卡、工作流面板、队列面板等缺失样式。
- 窗口自适应优化：中等宽度下创作页改为“编排 + 结果”双列、参数检查器下移；吸顶面板在矮窗口不再被裁切；窄窗口顶栏自动收敛，右侧按钮不再被截断。
- 模板卡片文本三行截断、按钮单行排布，修复半行文字与按钮溢出卡片的错位问题。

## 代理与网络

- 代理设置新增 SOCKS 支持：`socks5://`、`socks5h://`、`socks4://`、`socks4a://`，支持账号密码认证，未写端口时默认 1080。
- 新增独立 `src/main/socksProxy.ts`：手写 SOCKS4/SOCKS5 握手 + 认证 + TLS 隧道，通过 undici Agent 自定义 connector 接入，零新增第三方依赖。
- 系统代理解析同步支持 SOCKS/SOCKS4/SOCKS5 规则，PAC 解析结果可直接使用。
- 本地起 SOCKS5（无认证 / 带认证）与 SOCKS4a 服务端完成端到端验证，HTTP 与 HTTPS 请求均正常。

## 行业模板与提示词

- 内置模板扩充到 1120+ 条，覆盖 46 个行业，新增第二批行业场景包（电商活动/私域/售后/多尺寸、短剧预告/关系图/切片、自媒体口播/九宫格/数据长图、人物窗光/职业九宫格、二次元国风/赛博/拟人、虚拟IP三视图/直播开场、餐饮后厨/外卖打包等 60+ 场景）。
- 新增提示词体检层：自动检测并补齐构图、光线、质感、排版四类画面控制信息，40+ 行业各有专属描述，写入 prompt 末尾“画面控制”段。
- 新增行业负向提示词库，40+ 行业各自追加专属禁止项。
- 补齐逻辑改为只使用未重复场景，杜绝“行业爆款首图 2 / 3”这类凑数模板。

- 行业质量层扩展到 41 个行业，请求与创作页预览同步生效。
